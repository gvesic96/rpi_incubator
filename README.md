Raspberry Pi project - SMART EGG INCUBATOR

  Fully automated egg incubator for hatching chicken and other eggs. 
  Humidity and temperature monitoring, modified high torque servo motor for egg rotation. Time measuring with DS3231 RTC.
  Heater and circulation fan controlled through IRFZ44N MOSFET switching circuit protected with flywheel diode.
  Target temperature, humidity and working days set and monitored through GUI application created in Qt Creator.

  Temperature sensor DALLAS DS18B20 using Dallas 1-wire protocol.
  Humidity sensor DHT22 using general 1 wire protocol.
  Servo motor SG90 for opening and closing hatch for maintaining target humidity level.
  Modified high torque servo for rotating shelf with eggs on every 6 hours.
