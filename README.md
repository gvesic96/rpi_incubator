Raspberry Pi project - SMART EGG INCUBATOR

  Fully automated egg incubator for hatching chicken and other eggs. 
  Humidity and temperature monitoring, servo motor for egg rotation. Time measuring with DS3231 RTC.
  Heater and circulation fan controlled through IRFZ44N MOSFET switching circuit protected with flywheel diode.
  Target temperature, humidity and working days set and monitored through GUI application created in Qt Creator.
